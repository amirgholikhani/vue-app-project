# Vite + Vue 3 Project

This project is built with [Vite](https://vitejs.dev/) and [Vue 3](https://vuejs.org/), using [pnpm](https://pnpm.io/) as the package manager.  
It provides a fast development environment and optimized production build setup.

---

## 🚀 Features
- ⚡️ [Vite](https://vitejs.dev/) for blazing fast dev server and build
- 🖖 [Vue 3](https://vuejs.org/) with `<script setup>` support
- 📦 [pnpm](https://pnpm.io/) for efficient package management
- 🎨 [Tailwind CSS](https://tailwindcss.com/) (optional, if included)
- 🔧 ESLint + Prettier for code quality

---

## 📦 Getting Started

### Prerequisites
Make sure you have [pnpm](https://pnpm.io/installation) installed:

```bash
npm install -g pnpm

```
